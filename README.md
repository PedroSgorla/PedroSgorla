## 👨‍💻 Sobre mim

Sou desenvolvedor **fullstack com foco em backend**. Trabalho com **Java e Spring Boot** no backend. Também sou estudante de **Engenharia Mecatrônica** no IFCE (conclusão prevista em 2027).

### 🔧 Principais áreas de atuação:

Desenvolvimento backend com **Java** e **Spring Boot**, criando **APIs REST** organizadas em camadas  
Persistência de dados com **Spring Data JPA**, **Hibernate**, **JDBC** e **Spring Data MongoDB**  
Desenvolvimento frontend com **React**, **JavaScript** e **TypeScript**, consumindo as APIs que eu mesmo construo no backend  
Modelagem de dados **relacional** (PostgreSQL, MySQL) e **NoSQL** (MongoDB)  
Vim da área de **pesquisa e desenvolvimento**, de onde trouxe o hábito de depurar com método e prestar atenção nos detalhes  

### 🧠 Estudando agora:
